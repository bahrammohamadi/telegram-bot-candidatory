# ماتریس آزمون
`npm ci && npm test`: تست قواعد دامنه، feature flag و callbackهای مسدودشده، و مخزن وظیفه با Appwrite ساختگی. `npm run check` بررسی syntax منتخب را انجام می‌دهد؛ نمونه CI در `ci-example.yml` است و فعال نشده. هیچ Appwrite واقعی، Telegram، Worker، دیتابیس اصلی/Review، تست E2E، بار، مهاجرت، بازیابی، دسترس‌پذیری یا آزمون کاربر اجرا نشده است.
