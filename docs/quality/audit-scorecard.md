# ریسک‌ها و دروازه‌های باز
- منبع اصلی و وضعیت Worker، مینی‌اپ، دیتابیس و محیط Review نامعلوم؛ تطبیق عملی فاز صفر ناقص است.
- امکانات عملیات پیش‌فرض خاموش‌اند؛ قابلیت حذف/خروجی و اجرای AI غیرفعال‌اند.
- درخواست‌های همزمان تغییر وضعیت، ذخیره پیش‌نویس و چندمرحله‌ای جلسه تراکنشی نیستند؛ pagination نمایش‌ها ناقص و تأیید کامل وظایف نیازمند تست واقعی است. روش جلوگیری از تکرار با ID ثابت فقط روی مخزن ساختگی آزموده شده است.
- محدودسازی و قفل ادمین حافظه‌ای‌اند؛ webhook secret اختیاری و permissionهای دیتابیس زنده ناشناخته است.
- اسکریپت setup تطبیق کامل schema، آماده‌شدن indexها، بازیابی و حفظ انواع/مجوزهای فعلی را تضمین نمی‌کند.
- `npm audit --omit=dev` در ۲۰۲۶-۱۱-۱۱: سه آسیب‌پذیری گزارش‌شده (دو high، یک moderate؛ node-appwrite/undici/@fastify/busboy). بررسی exploitability و ارتقای سازگار/آزموده باز است.
- تست زنده، بازیابی، امنیت مستقل، UX، پرداخت و دسترس‌پذیری انجام نشده‌اند.
