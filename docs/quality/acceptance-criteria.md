# معیار پذیرش
اهداف سند از جمله اولین ارزش در سه دقیقه، تکمیل ۹۰٪ سناریوها، عدم تکرار یا فقدان وظیفه تأییدشده، استفاده بدون AI، WCAG 2.2 AA، بازیابی و تطبیق پرداخت هنوز اثبات نشده‌اند. هر قابلیت نیازمند طراحی تأییدشده، آزمون امنیت و یکپارچه، مستندات، بررسی دسترس‌پذیری و شواهد اجرا در محیط مناسب است. نتایج تست واحد جایگزین پذیرش تولید نیست.
