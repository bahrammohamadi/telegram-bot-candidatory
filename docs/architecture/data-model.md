# مدل داده و احتیاط مهاجرت
کد موجود از Appwrite و کالکشن‌های users، consultations و leads استفاده می‌کند؛ شناسه‌های واقعی و schema زنده تأیید نشده‌اند. `setup-db.js` برای `candidateProfile`، `opsState` و چهار کالکشن tasks/meetings/ai_jobs/audit_logs پیشنهاد افزایشی دارد؛ هنوز اجرا یا روی داده واقعی آزمایش نشده است. کالکشن تازه بدون مجوز عمومی ساخته می‌شود؛ مجوز کالکشن‌های موجود تغییری نمی‌کند و باید مستقل ممیزی شوند. اختلاف نام، نوع، حالت آماده‌بودن attribute/index و سازگاری schema با 409 قابل تأیید نیست. اسکریپت migration نسخه‌بندی‌شده و recovery تضمین‌شده نیست؛ آن را روی production اجرا نکنید تا ارزیابی و تأیید لازم انجام شود.

Appwrite کلید خارجی رابطه‌ای و کنترل همزمانی اتمی این کد را تضمین نمی‌کند. بررسی `version` قبل از update اتمی نیست. قفل، تراکنش و outbox پیاده نشده‌اند.
