# مدل دامنه آزمایشی
`src/domain/` شامل قواعد خالص وظیفه، مسیر، الزام، مجوز، AI job و audit است. مدل کنونی به کاربر تلگرام وابسته است و workspace، membership، foreign key و جریان کامل دوره فعالیت را پیاده نمی‌کند. تفکیک اعلان کاربر و تأیید رسمی در مدل وجود دارد، اما هیچ فرایند تأیید مرجع رسمی پیاده نشده است. تست واحد اثبات سازگاری با داده زنده نیست.
