# امنیت و حریم خصوصی
- احراز هویت ربات به صحت webhook وابسته است؛ `BOT_WEBHOOK_SECRET` اختیاری است و بدون آن وب‌هوک اعتبارسنجی نمی‌شود. پیکربندی و استقرار زنده تأیید نشده است.
- قفل تلاش ادمین و rate limit فقط حافظه فرایندند و در serverless/چند نمونه تضمین سراسری ندارند؛ بدون ADMIN_PASSWORD رفتار قبلی دسترسی بدون رمز حفظ می‌شود. احراز هویت قوی و لاگ اقدامات مدیریتی نیازمند کار بیشتر است.
- کنترل مالکیت برخی مخازن جدید موجود است؛ RBAC دامنه به همه مسیرها اعمال نشده. اسکریپت کالکشن جدید را بدون مجوز عمومی می‌سازد، اما مجوزهای فعلی DB ناشناخته‌اند و باید بررسی شوند.
- خروجی و حذف خودکار و اجرای پیش‌نویس AI غیرفعال‌اند. برای خروجی/حذف باید موجودی کامل داده‌ها، pagination، خطاها، سیاست نگهداری و تأیید کاربر طراحی و آزمایش شود. هیچ ادعای ناشناس‌سازی سوابق خرید نداریم.
- `logAudit` بهترین تلاش است و حسابرسی کامل یا عدم نشت تمام اطلاعات حساس را تضمین نمی‌کند. ممیزی مستقل، تست امنیت، بازیابی و بررسی همه Markdownها انجام نشده.
