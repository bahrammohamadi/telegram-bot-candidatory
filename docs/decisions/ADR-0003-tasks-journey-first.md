# ADR-0003: نمونه آزمایشی عملیات روی ربات موجود
نمونه امروز/مسیر/وظایف/جلسات در همین مخزن و پیش‌فرض خاموش است. این تصمیم به معنی تکمیل فاز یک یا آمادگی انتشار نیست؛ حفظ مسیرهای قبلی، آزمون یکپارچه و تأیید محصول پیش‌نیاز هستند. تأیید مسیر و اولویت‌های دیگر پس از تکمیل تطبیق سامانه زنده انجام می‌شود.
