# ADR-0002: عدم مهاجرت در این تغییر
وضعیت: تصمیم محدود به این patch، نه انتخاب نهایی زیرساخت. کد ربات مخزن از Appwrite استفاده می‌کند؛ Worker و دیتابیس زنده بررسی نشده‌اند. انتقال اتصال، کپی جدول یا migration انجام نشده است. انتخاب نهایی بعد از ارزیابی هزینه، سازگاری، سهمیه، پرداخت و بازیابی داده و تأیید مالک انجام می‌شود.
