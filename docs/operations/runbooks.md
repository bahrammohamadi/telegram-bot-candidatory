# راهنمای آزمایش ایزوله
فقط با داده مصنوعی، پروژه و دیتابیس ایزوله و مجوز صریح، schema و مجوزهای مورد انتظار را بررسی کنید؛ بعد از بررسی اسکریپت و بکاپ/بازیابی، `setup-db.js` را با شناسه‌های صریح اجرا و وضعیت واقعی همه attribute/indexها را جداگانه تأیید کنید. خطای 409 به معنای همسان بودن schema نیست. سپس می‌توان `ENABLE_EXPERIMENTAL_OPERATIONS=true` را برای بررسی دستی فعال کرد. خاموش‌کردن flag مانع دسترسی کاربران به فلوهای جدید است؛ داده ذخیره‌شده را حذف نمی‌کند. اجرای production هنوز تأیید نشده است.
