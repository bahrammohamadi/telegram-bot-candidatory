# پاسخ به رخداد
توقف انتشار و ارجاع به مسئول عملیات؛ جمع‌آوری لاگ بدون اطلاعات حساس؛ بررسی دامنه و زمان رخداد؛ تصمیم درباره بازگشت کد و بازیابی داده بر اساس طرح مصوب؛ ثبت رخداد و آزمون رگرسیون. بازگشت کد به تنهایی جایگزین بازیابی داده یا اصلاح ناسازگاری schema نیست. پایش و مسئولان هنوز باید تعیین شوند.
