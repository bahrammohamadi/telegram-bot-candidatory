# استقرار و دروازه انتشار
نمونه پیکربندی CI در `docs/quality/ci-example.yml` قرار دارد ولی workflow فعال نیست؛ استقرار خودکار از طریق این تغییر وجود ندارد. هیچ استقرار یا اجرای `setup-db.js` در این کار انجام نشده است. پیش‌فرض `ENABLE_EXPERIMENTAL_OPERATIONS=false` است؛ آن را روی production فعال نکنید. تغییرات پیش از انتشار به بررسی محیط واقعی، سازگاری env (شامل DATABASE_ID/APPWRITE_PROJECT_ID)، بازبینی schema و مجوزها، نسخه پشتیبان و آزمون بازیابی، تست یکپارچه و تأیید مالک نیاز دارند. `BOT_WEBHOOK_SECRET` باید با secret وب‌هوک تلگرام هماهنگ و در محیط امن تنظیم شود؛ توکن را در command line، لاگ یا مستندات واقعی ثبت نکنید.
