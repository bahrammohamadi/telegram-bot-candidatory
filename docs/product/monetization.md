# درآمدزایی
پلن‌های فعلی و قیمت‌ها در `src/constants/plans.js` قرار دارند؛ درخواست خرید از مسیر لید و مدیریت دستی انجام می‌شود. صحت جریان زنده و تطبیق پرداخت بررسی نشده است. قیمت ۶٬۹۰۰٬۰۰۰ تومان برای ۳۰ روز فقط فرضیه تأییدنشده است؛ هیچ قیمت یا entitlement موجود تغییر نکرده است. درگاه، webhook امضادار و دوره اشتراک باید جداگانه طراحی و آزموده شوند.
