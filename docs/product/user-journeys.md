# سفرهای کاربر
سفرهای فعلی ربات شامل ثبت‌نام/پروفایل، ارزیابی، داشبورد، یادگیری و درخواست خرید است؛ آزمون زنده انجام نشده است. سفر آزمایشی امروز ← وظیفه ← پیگیری و جلسه ← پیشنهاد اقدام ← تأیید، پشت feature flag خاموش است. خروجی/حذف و اجرای پیش‌نویس AI فعال نیستند. معیار اولین ارزش در سه دقیقه نیازمند آزمون با کاربران است.
