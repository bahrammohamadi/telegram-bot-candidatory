## وضعیت تغییرات معماری (پیش‌نویس)

تطبیق اولیه و محدودیت‌های بررسی در [تحلیل فاصله](docs/architecture/gap-analysis.md) و [فهرست ریسک‌ها](docs/quality/audit-scorecard.md) ثبت شده است. قابلیت‌های جدید امروز، مسیر، وظایف و جلسات آزمایشی و به‌طور پیش‌فرض خاموش‌اند؛ هنوز برای انتشار روی محصول اصلی آماده نیستند. Worker، مینی‌اپ و پایگاه داده زنده در این بررسی تأیید نشده‌اند. پیش از اجرای `setup-db.js`، ارزیابی سازگاری و آزمون بازیابی در محیط ایزوله و تأیید مالک لازم است.

آزمون محلی: `npm ci && npm test && npm run check`. نمونه تنظیمات CI در `docs/quality/ci-example.yml` است و هنوز به‌صورت GitHub Actions فعال نشده است.
